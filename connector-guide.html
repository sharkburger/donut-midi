Connect Neon to the website

Quick start on Mac

  1. Download the Mac disk image (.dmg). Open it, drag Donut MIDI Neon.app to Applications, then open the app. For later sessions, just open it from Applications.
  2. Install Python 3.11–3.14 if it is not already installed. The launcher does not bundle Python and is not Apple-notarized.
  3. Connect the glasses to the Companion phone, open Companion, and put the phone and computer on the same Wi-Fi. Enable Compute eye state if you want pupil and 3D eye data; it is not required for gaze notes.
  4. The app opens Terminal automatically. If macOS blocks the app, go to System Settings → Privacy & Security → Open Anyway, then confirm Open. Allow access to Terminal when prompted. These are first-launch permissions. Setup installs dependencies into ~/Library/Application Support/Donut MIDI/runtime and needs internet; later launches reuse them.
  5. The connector opens the public website with a fresh code. Click Connect local Neon. Allow local-network access if the browser asks.
  6. Click Start melody + accompaniment to enable audio and show the marked screen mat. Keep all four markers visible to the scene camera, then dwell on a donut.

If connecting fails

  • Browser blocks local access: use the Local fallback link printed in the connector window. This serves the same English app from your computer. Do not disable browser security or install an untrusted certificate.
  • Code expired: each restart generates a new code. Open the new link from the connector. Refreshing the webpage clears the code from memory; paste it again if needed.
  • Neon not found: check Companion and Wi-Fi. Guest Wi-Fi may isolate devices. For a manual IP, use the source ZIP and run python3 connector/launch.py --ip YOUR_PHONE_IP from its folder.
  • Port busy (source ZIP): the Mac app selects a free port automatically. For the source launcher, close the previous connector, or start with --port 8767. Keep the website port field aligned with the launcher.
  • No notes: enable sound, use Look or Aftertaste, keep four markers visible, and check the worn / surface status. Pupil calibration is only needed for body modulation.
  • Windows: download and extract the source ZIP, then use Start Neon Connector.bat with Python 3.11–3.14 installed. The Windows launcher has not yet been tested on Windows hardware.

Data and limitations

The local connector keeps only the latest scene-matched sample, at roughly 30 Hz. Scene images are processed locally for AprilTag mapping and are not sent to the webpage, recorded or uploaded by the connector. The webpage receives gaze, marker validity, pupil diameter and available native eye geometry. Research exports require explicit consent and remain local until you choose where to share them.

The public site still comes from GitHub Pages. Gaze and sound processing happen on your computer. Browser permissions and public-to-local access vary; the local fallback is included for blocked browsers. The cognitive model remains untrained: sound regions are self-report or artistic mappings.

Keep the terminal open while playing. Press Ctrl+C to stop the connector. A new session needs a new pairing code.
