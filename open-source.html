本地运行代码导览参与贡献依赖与许可

不需要构建工具。

git clone https://github.com/sharkburger/donut-midi.git
cd donut-midi
python3 serve.py
# http://127.0.0.1:8088/

也可解压下载包，在 Mac 双击“启动甜甜圈之歌.command”。官网与模拟／回放可静态部署或直接打开 HTML；Neon 请使用本机 HTTP 服务，另行安装并启动桥接。前端不需要 npm、CDN、API 密钥或构建步骤。

文件作用

从一个可复现的问题开始。

先搜索 GitHub Issues 是否已有同类问题。反馈时附上系统／浏览器、输入来源、操作步骤、预期与实际表现；设备问题请加 Python 与 Companion 版本。避免上传参与者数据或设备隐私。

欢迎改进教程、无障碍体验、真实硬件兼容性记录与自动测试。提交 Pull Request 时解释修改原因与验证方式，维护既有 donut-song/1 格式，注明模拟、合成数据与真实设备的区别。

名称与来源

网站统一使用 Donut Song／甜甜圈之歌；Donut Eye 是早期称呼，donut-midi 是仓库与部署路径。声音目前由 Web Audio 合成，并不提供 MIDI 输出。

内容组织参考 FlowIO 对项目介绍、工具、硬件文档、制作资源和贡献入口的分层方式。本网站的布局、文字与圆环视觉为本项目重新设计，没有使用其品牌与素材。
