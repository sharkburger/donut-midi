GET STARTED / 快速开始

第一首歌，从这里开始。

先模拟，再连接。选择适合你手边条件的路径。

01 无设备02 示例回放03 Neon 实时
无设备体验合成示例连接 Neon环境要求连接与恢复

01 / NO HARDWARE

没有设备，先试试。

  1. 打开模拟演奏台，输入来源保持“鼠标模拟”。
  2. 点击“开启声音与演奏”；浏览器会在这次主动点击后启动声音。
  3. 在三个甜甜圈区域停留约 500 ms，听 C4 / E4 / G4。离开后再进入可重奏。
  4. 拖动“模拟瞳孔”滑块，比较音色；它是合成输入，并非测量。
  5. 切换品尝、余味，手动点击“吃完了”。用“重新摆盘”恢复全部区域。

空格暂停／恢复声音；输入控件获得焦点时遵循控件行为。手机可拖动指针体验，但工作台优先面向桌面鼠标。

02 / SYNTHETIC EXAMPLE

让同一段输入，有不同的声音。

  1. 打开数据回放，点击“示例数据”。
  2. 点击“播放”，主动启动声音与回放。示例约 30 秒，全部由程序合成，非参与者数据。
  3. 调整音高、明亮度／颤音和调制强度。暂停后可回到开头再听。

你也可以导入本工具导出的 JSON。回放沿用输入和阶段，用当前声音映射重新配乐，不是原始音频重现。

03 / NEON LIVE

连接真实目光。

先在本机运行，公开网站不直连。

桥接只接受 http://127.0.0.1 或 http://localhost 来源；GitHub Pages 的 HTTPS 来源会被拒绝。浏览器还可能施加混合内容或本地网络权限限制。本版不提供公网直连承诺，也不建议关闭浏览器安全功能。真实 Neon 联调尚未完成。

准备设备与软件

  • Pupil Labs Neon、运行 Companion 的兼容手机，三个甜甜圈或小碟、打印桌垫、电脑和扬声器／耳机。
  • Python 3.11+，现代支持 Web Audio 和 WebSocket 的桌面浏览器。依赖安装可能因系统而异；原版检查环境为 macOS / Python 3.14。
  • 手机与电脑连接允许设备互通的同一局域网。桥接手机连接使用 8080 端口；本机网页 8088，WebSocket 8765。
  • 前端包含本地 p5.js，可离线模拟／回放。首次下载代码和安装 Python 依赖需要网络；Neon 仍需本地网络。

1. 下载与安装

git clone https://github.com/sharkburger/donut-midi.git
cd donut-midi
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r bridge/requirements.txt

Windows 的虚拟环境激活命令为 .venv\Scripts\activate；可使用 python 代替系统中不存在的 python3。在独立环境安装，避免影响已有研究环境。

2. 布置桌垫

下载 mat.svg ↓，A3 横向、保持比例打印。四角 AprilTag 36h11（ID 0–3）全部可见。将食物放在三个圆心附近，勿遮挡标记。查看打印与定位细节 →

3. 启动网页与桥接

打开 Companion，启用 Compute eye state 以提供瞳孔直径（名称可能随版本变化）。打开两个终端，均进入项目目录并激活虚拟环境：

# 终端 A：本机静态网页
python serve.py
# 打开 http://127.0.0.1:8088/play.html

# 终端 B：Neon 桥接
python bridge/neon_bridge.py
# 自动发现失败时，改用手机实际 IP：
python bridge/neon_bridge.py --ip 192.168.1.20

4. 连接、检查、采集

  1. 本机演奏台选择“Neon 实时”，地址保持 ws://127.0.0.1:8765，点击连接。
  2. 保持四角标记可见，分别看三个圆心，确认光标定位。系统定位固定区域，并不识别食物。
  3. 确认“注视与瞳孔可用”，点击“采集参考值 · 15 秒”，保持照明和观看位置稳定。有效样本不足将拒绝采集。
  4. 参考值就绪后，点击开启声音，进入观看。更换参与者时重新采集。

连接异常时，按顺序检查。

  • 无法连接桥接：确认页面地址是本机 HTTP，桥接终端没有退出，端口一致；不要从 file:// 或公开 HTTPS 官网连接。
  • 桥接已连，仍无数据：检查 Companion、眼镜佩戴与手机 IP，确认局域网没有客户端隔离。
  • 标记不可用：露出全部四角、避免反光、正视桌垫后逐个看圆心。缺少任何一个标记便暂停新选音。
  • 注视可用但无瞳孔：检查 Compute eye state。可选音，但不能启用有效的身体调制。
  • 数据失效或断开：超过 500 ms 未更新或未佩戴会停止新选音；实时掉线释放延音。恢复数据后重新检查定位，断开时点击重新连接。
