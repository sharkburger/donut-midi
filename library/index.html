Start your own sketch

Load p5.js, connector-client.js and p5.neon.js. Call neon.update() in draw().

const neon = new NeonP5();
// setup():
neon.useMouse(canvas);
// draw():
const gaze = neon.update();
if (gaze) circle(
  gaze.x * width,
  gaze.y * height, 20);
